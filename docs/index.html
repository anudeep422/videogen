Install VideoGen as an app
Opens full screen from your home screen and works offline.
📲 To install on iPhone: tap the Share button, then "Add to Home Screen".

Make a video in 3 steps

  1. ✏️ Animator → Templates → pick one → change the text.
  2. 🎹 Instrument Studio → ✨ One tap → choose mood and length → ☰ → Use in the Animator.
  3. In the Animator → Export → MP4 → upload to YouTube.
